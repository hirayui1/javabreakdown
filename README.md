# javabreakdown
This repo is my effort to build up knowledge over time and to keep a systematic track of my learning materials per java subject.

# Short term goal
My current goal is to revise the entirety of java fundamentals, and explain what I deem needs an explanation in my own words in comments next to them, which I will be doing in abundance.

# Long term goal
My greater goal with this repo is to keep coming back here every time I think "oh, you can do that?" and replicate the essentials in a simplified example, which then will have notes explaining it with my own thought process.

# Conclusion
Goal for this is long-term effort is to allow me to eventually master java in its entirety, and give me the confidence to say that I did, for however much I did at any time, while also being good practice and review material for future needs. I also like teaching my friends so it could possibly be a helpful teaching material.
